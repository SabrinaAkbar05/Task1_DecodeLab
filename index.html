Core Concepts

What you learn in Project 1

⟨/⟩

Semantic HTML

Use meaningful tags like <header>, <main>, <article>, and <footer> — no div soup.

#

CSS Engineering

External stylesheets only. DRY principle via BEM methodology. No inline styles — ever.

▦

Layout Systems

CSS Grid for macro page structure. Flexbox for micro component alignment. Right tool, right job.

♿

Accessibility (A11Y)

Alt text on every image. Contrast ratio above 4.5:1. Proper heading hierarchy — no skipped levels.

✓

W3C Validation

Zero errors allowed. Code must pass W3C Validator and Lighthouse Audit before it ships.

IA

Information Architecture

Structure before code. Define the sitemap first. Findable content, minimal cognitive load.

The Architect's Mandate

The frontend is the only part of the system the world will ever see.

Build it well. That means semantic integrity, clean separation of concerns, and code that any developer — or any assistive technology — can read and understand at a glance.
